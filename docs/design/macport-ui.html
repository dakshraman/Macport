Setup did not find bootable media
Firmware started and read the attached image, but no boot option was created. The machine stopped before the guest could run.
What happened

ArmVirtQemu read the El Torito image from the USB CD-ROM but did not publish a boot option for it, so the firmware fell through to the next device and stopped.

What to try
  1. Confirm the attached file is an optical image. A Windows ISO always is.
  2. Eject and re-attach the media from the dashboard.
  3. If it repeats, copy the details and send them with the log.
